# Сахалин — план путешествия

Личный планер зимней поездки на React, MobX и Ant Design. Каталог хранит идеи из заметок, план по дням — только то, что путешественники добавили как совместно выбранное. Стоимость согласованных пунктов и дополнительных расходов складывается в бюджете. Данные сохраняются в браузере.

## Запуск

```bash
npm install
npm run dev
```

Для локальной production-сборки:

```bash
npm run build
npm run preview
```

## Публикация на GitHub Pages

В репозитории уже настроен workflow `.github/workflows/deploy.yml`: он собирает приложение при push в `main` и публикует папку `dist` через GitHub Pages. В настройках репозитория выберите **Settings → Pages → Build and deployment → GitHub Actions**.

Для SPA используется `HashRouter`, поэтому маршруты открываются на GitHub Pages без отдельной серверной настройки. Базовый путь сборки настроен на репозиторий `TravelTrips`.
